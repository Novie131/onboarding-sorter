報到文件分類網頁　使用說明
================================

這個小工具可以把「一整疊報到文件的掃描檔」自動切成每個人一份，
判斷每份文件是什麼、用 AI 讀手寫姓名／學號對應到名單，
建好資料夾、改好檔名，最後打包成一個壓縮檔給你下載。


一、啟動服務
--------------------------------
（套件已經裝在資料夾裡的 .venv，不用再裝。）

在 Pi 的終端機輸入：
    cd /home/imac/onboarding-sorter
    setsid nohup .venv/bin/python -m streamlit run app.py --server.headless true > streamlit.log 2>&1 < /dev/null &

然後在瀏覽器打開：
    ・這台 Pi 本機：http://localhost:8501
    ・內網其他電腦：http://192.168.2.22:8501

停止服務：
    pkill -f "[s]treamlit run app.py"

※ 改了 .env 之後，要先停止再啟動，設定才會生效。

（如果之後要重新安裝套件：
    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt ）


二、設定 AI 模型（只要做一次）
--------------------------------
AI 會幫你讀健康聲明書上的手寫姓名、學習指導實施計畫上的學號，
自動對應到名單上的人。
模型要放在你們自己、有獨立顯示卡的伺服器上。
建議用 Ollama 跑 gemma4:26b（vLLM 也可以，換伺服器只要改 .env）。

1. 用文字編輯器打開資料夾裡的「.env」檔（檔名前面有一個點）。
2. 填這兩個值：
   LLM_BASE_URL=模型伺服器的網址，結尾一定要有 /v1
       Ollama 例：http://模型伺服器IP:11434/v1
       vLLM 例：  http://模型伺服器IP:8000/v1
   LLM_MODEL=模型名稱
       Ollama：在模型伺服器執行 ollama ls，看 NAME 那一欄（例如 gemma4:26b）
       vLLM：  執行 curl 網址/v1/models，看裡面的 "id"
   如果伺服器有設 API 金鑰，再填 LLM_API_KEY；沒有就留空。
   下面這幾個可以不填，不填就用預設值：
   LLM_TIMEOUT=120       每次請求最多等幾秒
   LLM_MAX_TOKENS=1024   AI 回覆的字數上限
   LLM_EXTRA_BODY=       進階用，一般留空
3. 存檔，然後重新啟動服務（見第一節）。
4. 測試能不能用，兩種方法擇一：
   ・在終端機執行：.venv/bin/python check_llm.py
     看到「✓ 連線成功」和「✓ 看圖正常」就 OK 了，還會顯示回應花了幾秒。
   ・或在網頁左邊側邊欄按「測試連線」。

★ 常見問題
  ・出現「模型沒有回覆內容…請調高 LLM_MAX_TOKENS」：
    Gemma 4 會先「思考」再回答，字數上限太小時答案會被截掉。
    在 .env 加上（或改成）LLM_MAX_TOKENS=2048，存檔後重新啟動服務。
  ・第一次分析特別慢或逾時：模型要先載入顯示卡，等一下再按一次「開始分析」就好。
  ・連不到伺服器：確認 IP、埠號，以及模型伺服器有開放內網連線
    （Ollama 要設定 OLLAMA_HOST=0.0.0.0:11434）。

★ 沒設定模型也能用！這時候會「依名單順序」預設配對，
  名單照掃描的順序貼上就好，下一步就不用調整。
  只是「夾在別人那套後面的學習指導實施計畫」要你自己選是誰的。


三、每次使用的步驟
--------------------------------
1. 丟入掃描檔
   把掃描好的 PDF 拖進網頁。可以一次丟好幾個，
   程式會依「檔名順序」接起來（掃描機的檔名有時間，所以就是掃描的順序）。

2. 貼上名單
   每行一位，寫「學號 姓名」就可以，例如：
       1411230001 王小明
   也可以直接從 Excel 複製「組別、學號、姓名」幾欄貼上。
   有設定 AI 的話，名單順序不限，隨便排都可以。
   ★ 只補交「學習指導實施計畫」的人（例如上一批的同學），也要放進名單！

3. 按「開始分析」
   程式會切出每一套文件、分出每份文件的種類，再請 AI 讀姓名／學號、自動選好是誰。
   畫面會告訴你：總共幾頁、略過幾張空白頁、找到幾套文件、
   幾組學習指導實施計畫、名單有幾位。

4. 看一眼核對（很重要！）
   上半部：每一套文件一行
   ・左邊：健康聲明書上的手寫姓名
   ・右邊：AI 選好的人（可以自己改）
   ・下面：型態同意書是哪一種（研究獎助生／兼任研究助理）、「AI 讀到『…』」
   下半部：每一組「學習指導實施計畫」一行
   ・左邊：表單上的學號、姓名
   ・右邊：AI 依學號選好的人（可以自己改）
   ★ 黃色的一定要仔細看，必要時自己改選。
     其他的也建議快速掃過一遍，確認左右一樣。
   某一套／某一組不要輸出的話，選「（略過）」。

5. 按「分類並打包」，再按「下載壓縮檔」
   就完成了！


四、壓縮檔裡面有什麼
--------------------------------
  報到文件分類_日期_時間.zip
  ├─ 組別／學號_姓名／
  │   ├─ 姓名-健康.pdf                          個資同意書 + 健康聲明書 2 頁
  │   ├─ 姓名-型態.pdf                          勾「兼任研究助理」的型態同意書
  │   ├─ 國科會計畫-姓名-型態.pdf               勾「研究獎助生」的型態同意書
  │   ├─ 國科會計畫-姓名-學習指導實施計畫.pdf   實施計畫 2 頁 + 評量表 1 頁
  │   └─ 姓名-其他.pdf                          認不出來的頁（正常不會出現）
  └─ 分類清單.csv
          （每個檔案對應到原始掃描檔的第幾頁，可以直接用 Excel 打開）

  ・「國科會計畫-」開頭的檔案 ＝ 研究獎助生的文件。
  ・沒有的文件就不會產生那個檔，例如一般人只有「健康」和「型態」兩個檔。
  ・只補交實施計畫的人，資料夾裡就只有那一個檔。
  ・名單沒有寫組別的話，就不會有組別那一層資料夾。
  ・「通知」和「體檢項目表」是大家都一樣的印刷品，所以不會輸出。
  ・型態同意書是橫的表格，掃描起來是側躺的，程式「不會」幫你轉正。


五、程式是怎麼判斷的？
--------------------------------
・切文件：靠每一套最前面那張「通知」（大家都一樣的印刷品）
  判斷「新的一套從這裡開始」，再依固定順序切出各個表格。
  雙面掃描的空白背面會自動跳過。

・分種類：體檢項目表後面的頁，
  - 側躺的橫式表格 → 型態同意書。看「指導教授的紅色印章」蓋在哪一欄：
    蓋在「研究獎助生」那欄 → 國科會計畫；蓋在「兼任研究助理」那欄 → 一般型態。
  - 直式的 3 頁 → 學習指導實施計畫（2 頁）＋ 評量表（1 頁）。

・認人：
  - 每一套：把「健康聲明書姓名欄小圖」連同名單給 AI，問它「這是名單上的誰」。
  - 學習指導實施計畫：讀表單上的「學號」，跟名單上的學號一模一樣就直接認定。
    所以夾在別人那套後面的實施計畫，也會歸到正確的人。
  AI 也會看錯，所以黃色的一定要人工確認。

・黃色提醒是什麼意思？（不會擋住你，只是請你多看一眼）
  「AI 讀到『…』，沒把握，請確認」
      → AI 不確定、讀錯字，或沒找到對應的人。
  「型態同意書判斷不出勾哪一型」
      → 沒蓋紅色印章、用黑色章，或章蓋在中間。檔案會先歸成一般「型態」，請自己確認。
  「有 2 張勾『…』的型態同意書」
      → 同一種型態有 2 張，會合併成同一個檔，確認一下。
  「沒有找到型態同意書」
      → 這個人可能沒交，或掃描時漏掉了。
  「同一套裡的第 2 組，可能是別人的」
      → 這套後面多夾了一組實施計畫，請對照學號選對人。
  「這組有 ○ 頁（正常是 3 頁）」
      → 實施計畫或評量表可能少了一張。
  「第 ○ 頁認不出是什麼文件」
      → 會另存成「姓名-其他.pdf」，請看一下是什麼。
  「這一套只有 ○ 頁，可能缺頁」
      → 這個人可能少交了某一張，或掃描時漏掉了。
  「第 5 頁看起來不是體檢項目表，頁序可能不對」
      → 這一套的紙可能疊錯順序。
  「第 ○ 頁在第一份『通知』之前，已略過」
      → 掃描檔最前面有不是通知的頁面，那些頁不會被輸出。

・使用前提：每個人的文件前 5 頁要照這個順序疊好再掃描：
    通知 → 個資同意書 → 健康聲明書(2頁) → 體檢項目表
  後面再接型態同意書、學習指導實施計畫（順序不限）。
  整份掃描檔的第一張（非空白的）一定要是「通知」。


六、附加功能：合併 PDF
--------------------------------
網頁上方切到「合併 PDF」分頁，可以把好幾個 PDF 接成一份：
1. 選擇要合併的 PDF（至少 2 個，可一次多選）。
2. 選擇合併順序：依檔名（預設），或依加入順序。
   畫面會列出順序和每個檔案的頁數，請確認一下。
3. 按「合併」，再按「下載合併後的 PDF」。
頁面會維持原本的方向。這個功能不會用到 AI。


七、隱私
--------------------------------
・掃描檔只在這台 Pi 上處理。
・有設定 AI 時，「只有」兩種小圖會送到 .env 設定的模型伺服器：
  健康聲明書的姓名欄、學習指導實施計畫的學號／姓名欄。
  都不含身分證字號，也不會送出整頁或個資同意書。
・網頁有開放給內網使用：同一個內網的人都能連進來使用，不需要登入。
  請不要在路由器上把 8501 埠轉發到外網。
